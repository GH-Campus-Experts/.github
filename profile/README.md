Welcome to the official GitHub Community for **Rungta International Skills University (RISU)**. We are a collective of driven student developers, aspiring GitHub Campus Experts, and open-source contributors dedicated to elevating the tech ecosystem on campus.

---

### 🚀 Our Core Objectives
- **Open Source Advocacy:** Guiding students from their first PR to becoming active open-source maintainers.
- **Skill Development:** Hosting elite bootcamps on Version Control, DevOps, Web Development, and AI.
- **Hackathons & Build-Days:** Transforming caffeine and code into real-world solutions.
- **Global Networking:** Connecting our campus with global tech communities and industry leaders.
